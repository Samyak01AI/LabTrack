# LabTrack — Working Prototype

A deliberately simple, handcrafted faculty-side prototype for tracking a student's progress throughout a semester.

## Run in VS Code
1. Extract the ZIP.
2. Open the `LabTrack` folder in VS Code.
3. Open `index.html` directly in a browser, or use the **Live Server** extension if available.
4. No npm install, database, backend, or internet connection is required.

## Demo flow to show faculty
- **Overview:** class snapshot and students who may need review.
- **Students:** open a student profile and see their longitudinal record.
- **Progress records:** add anything the faculty wants — lecture task, assignment, practical, extra work, observation, etc.
- **Additional tasks:** assign remedial/practice/improvement work and track status.
- **My criteria:** demonstrate that criteria are faculty-defined and can be added/removed.
- **Annual reports:** open a student's consolidated report and use **Print / Save PDF**.

## Important prototype note
This version intentionally uses localStorage and fictional demo data. It is a front-end working prototype, not the final multi-user production system.
