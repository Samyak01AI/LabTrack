1. Problem Specification

SPEC-REV: 2.1

Design a computational cache structure compliant with the Least Recently Used (LRU) eviction policy. The cache operates as a deterministic, fixed-capacity storage mechanism where every retrieval and storage mutation occurs in strict worst-case O(1) time.

Abstract Class Signature & Semantics

  • LRUCache(int capacity) Initializes the cache with positive integer boundary capacity. Allocates internal sentinel nodes and reserves hash buckets.
  • int get(int key) Returns the numerical value if key exists, otherwise returns -1. Successful queries immediately elevate the queried node to the Most Recently Used (MRU) rank.
  • void put(int key, int value) Updates the existing value or creates a new key-value pair. If total active keys exceed capacity, the Least Recently Used (LRU) key must be evicted and its memory cleanly deallocated prior to inserting the new entry.

2. Architectural Invariants & Topology

To satisfy O(1) average complexity, combine an internal Doubly Linked List (giving O(1) pointer detachment and head splicing) with an auxiliary Hash Map linking keys to heap node memory pointers.

Dual-State Data Structure Map Heap Topology Visualization
Invariant I: Recency Ordering

The node immediate successor to head.next MUST always correspond to the most recently touched key. The immediate predecessor to tail.prev MUST always point to the eviction candidate.

Invariant II: Bijection Map Integrity

For every active node N in the list, there exists exactly one key in the hash table pointing to N. No orphaned pointers or dangling iterators may persist post-eviction.

verified Pattern: Dummy Sentinel Nodes

Allocate persistent sentinel head and tail structs in the constructor. Link head->next = tail and tail->prev = head. This completely guarantees you never have to write branch conditionals checking for nullptr during insertion or mid-list node excision.

Decomposition Routine
  • • addNode(Node* n): Insert immediately after head.
  • • removeNode(Node* n): Splice out arbitrary node.
  • • moveToHead(Node* n): Call remove then add.
  • • popTail(): Evict tail->prev.
warning Critical Traps to Avoid
  • • Updating an existing key without adjusting its recency.
  • • Deleting node from list but forgetting map.erase(node->key).
  • • Forgetting explicit C++ destructor loop causing Valgrind test failures.
